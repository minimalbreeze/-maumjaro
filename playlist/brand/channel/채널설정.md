# minimalbreeze 유튜브 채널 설정

올릴 때 이 파일 보고 그대로 채우면 된다.

## 이미지

| 올릴 곳 | 파일 | 규격 |
|---|---|---|
| 프로필 사진 | `profile-800.png` | 800×800. 동그랗게 잘린다 |
| 배너 (채널 아트) | `banner-2048x1152.png` | 2048×1152 |

배너는 기기마다 보이는 영역이 다르다. 글자는 가운데 **1546×423** 안에만 넣었다 —
그 띠가 어느 기기에서나 보이는 영역이다. 바깥쪽 그림은 TV 에서만 다 보인다.

프로필은 48px 로 줄어도 읽히는지 확인했다(`profile-48.png`). 마크가 원 대비
78% 라 작은 화면에서도 형태가 산다.

## 채널명 · 핸들

```
채널명    minimalbreeze
핸들      @minimalbreeze
```

핸들이 이미 쓰이고 있으면 `@minimalbreeze.kr` → `@minimalbreezemusic` 순으로.
**채널명에 "플레이리스트" 를 붙이지 않는다.** 나중에 음악 말고 다른 걸 할 때
이름이 발목을 잡는다.

```
창이 큰 어느 곳의, 조용한 시간.

틀어두고 하던 일을 하세요.
읽을 때, 쓸 때, 아무것도 안 할 때.

귀를 잡지 않는 음악만 고릅니다.
오래 틀어둘수록 좋은 쪽으로.

모든 음원은 상업적 이용이 허용된 라이선스로만 쓰고,
출처는 영상마다 설명란에 밝힙니다.
```

## 짧은 소개 (채널 상단 한 줄)

```
틀어두고 하던 일을 하세요.
```

## 채널 키워드 (설정 → 채널 → 기본 정보)

```
플레이리스트, playlist, 작업할때듣는음악, 공부할때듣는음악, 재즈,
jazz, lofi, 카페음악, 집중, 백색소음, BGM, 피아노, 잔잔한음악
```

## 영상 제목 양식

```
[계절·장소] | [용도] 플레이리스트 [길이]
```

예:
- `가을 저녁, 창이 큰 로비에서 | 작업할 때 듣는 재즈 플레이리스트 [43분]`
- `겨울 아침, 아무도 없는 라운지 | 집중할 때 듣는 피아노 [1시간]`

**장소와 시간을 제목 앞에 둔다.** 이 채널이 파는 것은 곡이 아니라 장면이다.
사람들이 "그 로비 채널" 로 기억하게 만드는 자리다.

## 안 할 것

- 채널명·제목에 낚시를 쓰지 않는다 (`❗️`, `충격`, `이것만 들으면`)
- 썸네일에 얼굴을 넣지 않는다 — 이 채널의 얼굴은 그 방이다
- 매 영상마다 배경을 바꾸지 않는다. 계절이 바뀔 때만 바꾼다
