# 배경 그림 규칙

집마다 그림이 바뀐다. 바뀌어도 되는 것과 절대 안 바뀌는 것을 적어 둔다.
그림은 코드가 만드는 게 아니라 매번 사람이 지시해서 그리는 부분이라,
적어 두지 않으면 집마다 조금씩 달라진다. 실제로 2집에서 LP가 빠졌다.

## 고정 — 매번 반드시 들어간다

| 요소 | 설명 |
|---|---|
| **LP 턴테이블** | 로비 가구 배치 안에 자연스럽게 놓인다. 억지로 세워두지 않는다. 뚜껑이 열린 채 레코드가 돌아가는 모습. ⚠️ **2026-11-12 효성님: "LP가 들어가는 건 고정이다."** 1집에는 있었고 2집에서 빠졌다. 다시 빠뜨리지 않는다 |
| **큰 통유리 커튼월** | 바닥에서 천장까지. 계절은 이 창밖이 말한다 |
| **사람 없음** | 로비는 비어 있다. **예외: 보컬 집(12·13집)만 사람 한 명을 넣는다** — 2026-11-20 효성님 지시. 목소리가 주인공인 집이라 사람이 있어야 그 집의 성격이 읽힌다. 얼굴은 또렷하지 않게(옆모습·역광), 노래하는 자세나 마이크는 넣지 않는다 — 콘서트 영상처럼 보이면 안 된다. 보컬이 아닌 집은 그대로 비워 둔다 |
| **밝은 장면** | 어둡게 가지 않는다. 2026-11-11에 밤으로 그렸다가 "너무 어둡다"고 다시 그렸다 |
| **화면 아래 가운데 여백** | 자막 띠·이퀄라이저·로고가 올라갈 자리 |
| **현대적인 일본 애니메이션 배경화 화풍** | 또렷한 선, 부드러운 셀 셰이딩. 사진 같지 않게, 흐릿하지 않게 |

## 받은 그림은 확대해서 글자를 찾는다

⚠️ 2026-11-19. 11집 그림의 LP 재킷에 `HOLIDAY JAZZ` 가 또렷이 박혀 있었다.
축소판에서는 안 보이고 1920×1080 으로 받아서 그 부분만 잘라 봐야 보인다.
11집은 캐럴 집이라 내용까지 틀린 글자였다.

그림을 받으면 **LP 재킷·책등·간판·포스터 자리를 잘라서 확대해 본다.**
글자가 있으면 구도는 그대로 두고 글자만 지워 다시 뽑는다
(같은 그림을 imageReferences 로 주고 "글자를 지워 달라" 고 한다).

```
ffmpeg -i art/0NN-*.png -vf "crop=420:300:0:560,scale=840:600" /tmp/crop.png
```

"최초 우리가 계획한 글씨 이외에는 다른 거 넣지 마라" 는 영상 위에 얹는
자막만이 아니라 **그림 안에 그려진 글자**에도 적용된다.

## 발행한 집은 다시 고치지 않는다

⚠️ **2026-11-12 효성님: "001, 002는 발행했으니 다시 고치지 마라."**
올라간 영상의 그림·오디오·오버레이는 손대지 않는다. 코드를 고쳐서 결과가
달라지더라도 지난 집을 다시 뽑아 올리지 않는다. 고친 것은 다음 집부터
적용한다.

**계절감은 창문과 로비의 그림으로만 표현한다.**
글자로 "가을", "winter" 라고 쓰지 않는다. 영상에도 썸네일에도 쓰지 않는다.

| 집 | 창밖 |

| 002 | 늦가을 늦은 오후, 금빛 노을 + 로비 오른쪽 가장자리에 트리 |

효성님이 보낸 사진(층고 높은 고전 호텔 로비 — 크리스털 샹들리에, 바닥까지

보고 그렸다. 참고 사진이 올 때마다 로비는 바뀔 수 있다. 바뀌지 않는 것은
위의 '고정' 표다.

## 크기

1920×1080 PNG. 파일 이름은 `<집번호>-<설명>.png` (예: `003-lobby-earlywinter.png`).
`build.mjs --vol 003` 이 `003-` 으로 시작하는 파일을 찾아 쓴다.

Canva 로 뽑을 때 1280×720 으로 나오면 디자인에 1920×1080 페이지를 따로
만들어서 거기서 내보낸다. 1280을 늘리면 흐려진다.

## 글자를 못 지울 때 — 그 자리만 덮는 법 (2026-11-24)

위에 적힌 방법(같은 그림을 imageReferences 로 주고 "글자를 지워 달라")이
**서버 오류로 실패할 때가 있다.** 다시 돌리면 구도까지 바뀌어서 처음부터
고르는 일이 된다. 글자가 작고 주변이 단색이면 **ffmpeg 로 그 자리만 덮는
쪽이 빠르고 안전하다.**

4시간 크리스마스 그림에서 두 군데를 그렇게 지웠다 —
LP 재킷의 붉은 글씨 세 줄, 피아노 건반 덮개의 금색 명판.

**① 흐려서 지우기** (주변이 단색일 때)

```bash
ffmpeg -i 원본.png -filter_complex \
  "[0:v]crop=22:24:336:636,boxblur=7:4,format=rgba,\
geq=r='r(X,Y)':g='g(X,Y)':b='b(X,Y)':a='255*min(1,min(min(X,21-X),min(Y,23-Y))/5)'[p];\
   [0:v][p]overlay=336:636" 결과.png
```

`geq` 의 `a=` 가 가장자리를 투명하게 만든다(5px 페더). 이게 없으면 네모가
그대로 보인다.

**② 옆에서 떠다 덮기** (흐리면 얼룩이 질 때)

피아노 명판은 ①로 하니 흐린 네모가 남았다. 같은 덮개면의 **왼쪽 깨끗한
부분**을 떠서 올리니 자국이 없어졌다. crop 위치만 깨끗한 쪽으로 잡고
overlay 위치를 글자 자리로 준다.

**⚠️ `delogo` 는 쓰지 마라.** 테두리 픽셀을 끌어와 메우는데, 옆에 밝은
선(재킷 모서리)이 있으면 그 색을 끌어와서 **글자보다 더 눈에 띄는 밝은
네모**가 생긴다. 실제로 그랬다.

**위치 찾는 법** — 격자를 깔아 놓고 보면 좌표가 바로 나온다.

```bash
ffmpeg -i 원본.png -vf \
  "crop=60:60:320:620,scale=900:900:flags=neighbor,drawgrid=w=150:h=150:t=1:c=cyan@0.6" \
  /tmp/grid.png     # 한 칸 = 원본 10px, 좌상단 = (320,620)
```

고치고 나면 **같은 자리를 10배 이상 확대해서 다시 본다.** 흐린 네모나
이음매가 남았는지는 그 배율에서만 보인다.
