# 배경 그림 규칙

집마다 그림이 바뀐다. 바뀌어도 되는 것과 절대 안 바뀌는 것을 적어 둔다.
그림은 코드가 만드는 게 아니라 매번 사람이 지시해서 그리는 부분이라,
적어 두지 않으면 집마다 조금씩 달라진다. 실제로 2집에서 LP가 빠졌다.

## 고정 — 매번 반드시 들어간다

| 요소 | 설명 |
|---|---|
| **LP 턴테이블** | 로비 가구 배치 안에 자연스럽게 놓인다. 억지로 세워두지 않는다. 뚜껑이 열린 채 레코드가 돌아가는 모습. ⚠️ **2026-11-12 효성님: "LP가 들어가는 건 고정이다."** 1집에는 있었고 2집에서 빠졌다. 다시 빠뜨리지 않는다 |
| **큰 통유리 커튼월** | 바닥에서 천장까지. 계절은 이 창밖이 말한다 |
| **사람 없음** | 로비는 비어 있다 |
| **밝은 장면** | 어둡게 가지 않는다. 2026-11-11에 밤으로 그렸다가 "너무 어둡다"고 다시 그렸다 |
| **화면 아래 가운데 여백** | 자막 띠·이퀄라이저·로고가 올라갈 자리 |
| **현대적인 일본 애니메이션 배경화 화풍** | 또렷한 선, 부드러운 셀 셰이딩. 사진 같지 않게, 흐릿하지 않게 |

## 발행한 집은 다시 고치지 않는다

⚠️ **2026-11-12 효성님: "001, 002는 발행했으니 다시 고치지 마라."**
올라간 영상의 그림·오디오·오버레이는 손대지 않는다. 코드를 고쳐서 결과가
달라지더라도 지난 집을 다시 뽑아 올리지 않는다. 고친 것은 다음 집부터
적용한다.

## 집마다 바뀌는 것 — 계절

**계절감은 창문과 로비의 그림으로만 표현한다.**
글자로 "가을", "winter" 라고 쓰지 않는다. 영상에도 썸네일에도 쓰지 않는다.

| 집 | 창밖 |
|---|---|
| 001 | 가을 저녁, 단풍 든 산과 노을 |
| 002 | 늦가을 늦은 오후, 금빛 노을 + 로비 오른쪽 가장자리에 트리 |
| 003 | 초겨울 이른 아침, 첫눈과 서리, 잎 떨어진 가지, 은빛 하늘 |

003 부터 로비 자체가 바뀌었다. 1·2집은 모던한 호텔 로비였고, 003 은
효성님이 보낸 사진(층고 높은 고전 호텔 로비 — 크리스털 샹들리에, 바닥까지
닿는 긴 창과 커튼, 크림색 암체어 무리, 윤나는 대리석, 그랜드 피아노)을
보고 그렸다. 참고 사진이 올 때마다 로비는 바뀔 수 있다. 바뀌지 않는 것은
위의 '고정' 표다.

## 크기

1920×1080 PNG. 파일 이름은 `<집번호>-<설명>.png` (예: `003-lobby-earlywinter.png`).
`build.mjs --vol 003` 이 `003-` 으로 시작하는 파일을 찾아 쓴다.

Canva 로 뽑을 때 1280×720 으로 나오면 디자인에 1920×1080 페이지를 따로
만들어서 거기서 내보낸다. 1280을 늘리면 흐려진다.
