# 그루브 확장 기획 — 로파이 힙합 · 소울 · 펑크 (2026-11-27)

효성님 지시 — "음악을 힙합 R&B 분야로 그루브 있는 음원까지 늘리자.
그렇게 해서 첫 번째 긴 영상을 기획해 달라."

이 문서는 **기획이지 결정이 아니다.** 아래 "넘어야 할 문" 두 개를 통과해야
시작한다.

14집 때 정한 **새 주제 4점 검사**를 그대로 돌렸다(`발행계획.md`).

| 검사 | 결과 |

| ② 밝기 거르개가 다 버리나 | 통과 — 기준을 -14 → **-11** 로 풀면 된다. chillhop 11곡 중 5곡 통과 |
| ③ 시그니처를 깨나 | **안 깬다** — LP·로비 그림·이퀄라이저 그대로. 장르만 바뀐다 |
| ④ 추천이 엉뚱한 사람에게 가나 | **오히려 정확하다** — 아래 |

④ 가 14집에서 운동 집을 접게 만든 이유였는데, 이번엔 반대다.
실제 유입 검색어에 **`blue archive lofi`** 가 있었다(`발행계획.md`).
우리를 찾아오는 사람 중에 이미 로파이를 찾던 사람이 있다는 뜻이다.
유튜브에서 "lofi hip hop" 은 틀어두는 음악의 **본진**이고, 우리가
지금 받는 추천(69.4%)과 같은 자리다.

### ⚠️ hiphop 태그를 핵심으로 쓰지 않는 이유

받아 보면 **타입 비트와 상업곡 재현이 쏟아진다.** 실제로 상위에 나온 것들:

- `FREE Post Malone Type Beat`
- `Drake- Still Here instrumental (reprod. J...)`
- `Clayton Kershaw (feat. Evan Coles) ~ Instrumental Version`
- `RnB Chill Trap`

**`Drake- Still Here instrumental` 같은 것이 제일 위험하다.**
CC BY 는 **녹음**에 대한 허락이지 **작곡**에 대한 허락이 아니다. 남의 곡을
다시 연주해 올린 것은 멜로디 저작권이 그대로 살아 있고, Content ID
멜로디 주장은 **이의로 못 푼다** — 4집 It's Beginning to Look a Lot Like
Christmas 와 똑같은 함정이다(`저작권주장.md`).

같은 조건에서 **chillhop** 은 `Georgetown Cafe` · `Lofi machine` ·
`The Wise Man's Fear` 처럼 창작곡이 대부분이었다. 타입 비트는 11곡 중 1곡.

**그래서 chillhop 을 축으로 삼고, hiphop 은 보조로만 섞는다.**
그리고 제목 거르개에 아래를 더한다.

```
type beat · typebeat · reprod · prod. by · remake · cover ·
instrumental version · free beat
```

유명 아티스트 이름(drake · post malone · travis · weeknd · sza ...)도
제목에 있으면 거른다. 재현곡은 거의 전부 이름을 제목에 박아 둔다.

## 넘어야 할 문 둘

### 문 1 — wow 필터가 비트를 망치나 (사람 귀로만 판단된다)

`build.mjs` 의 LP 체인에는 `vibrato=f=0.33:d=0.012` 가 있다. 턴테이블의
미세한 피치 흔들림을 흉내 낸 것이고 **이 채널의 시그니처**다.

14집 때 배운 것 — **박자가 또렷한 곡에 걸면 흔들리는 게 그대로 들린다.
고장 난 것처럼 들린다.** 힙합은 박자가 또렷한 음악이다.

다만 로파이 힙합은 원래 테이프 흔들림을 미학으로 쓰는 장르라,
오히려 어울릴 수도 있다. **둘 중 어느 쪽인지는 들어 봐야 안다.**

2026-11-27 에 `Lofi machine` 40초로 비교본을 만들어 효성님께 보냈다
(① 원본 ② 지금 체인 ③ wow 뺀 체인).

- ② 가 괜찮다 → 아무것도 안 바꾸고 그대로 간다. **이게 제일 좋다.**
- ② 가 흔들린다 → 그루브 집에서만 wow 를 끈다. 나머지 체인(저역·고역·
  압축·스테레오)은 그대로라 LP 질감은 남는다. **시그니처를 반쯤 지킨다.**
- ③ 도 이상하다 → **접는다.** 체인 전체를 끄는 것은 14집에서 안 된다고
  이미 결론 낸 일이다.

### 문 2 — 한 집 먼저 만들어 시청 지속 시간을 본다

12·13집(보컬) 때 정한 방식 그대로다 — **시리즈로 시작하지 않는다.**
한 편 만들어 올리고 **시청 지속 시간**이 지금 평균(3:47)보다 높으면 더 간다.

긴 영상은 집 네 개를 이어 붙여 만드는 것이라, 집 하나가 안 되면
네 개는 더 안 된다. 순서를 거꾸로 하지 않는다.

## 새 무드 네 개 (`jamendo.mjs` 에 더할 것)

```js
로파이힙합: { groups: ['chillhop', 'triphop', 'hiphop'], speed: 'medium' },
소울그루브: { groups: ['soul', 'rnb', 'funk'], speed: 'medium' },
재즈퓨전:   { groups: ['jazzfusion', 'nujazz', 'smoothjazz'], speed: 'medium' },
다운템포:   { groups: ['downtempo', 'lounge'], speed: 'medium' },
```

`BRIGHT_BY_MOOD` 에도 넣는다 — 네 무드 모두 `-11`.
하이햇이 들어가 기본값 -14 로는 거의 다 버려진다.

| | |
|---|---|
| 구성 | 020 + 021 + 022 + 023 |
| 길이 | 약 3시간 40분 ~ 4시간 |
| 제목(안) | `밤에 하는 일이 있어서 틀어둡니다 🌙 로파이 힙합과 소울 그루브 [4시간]` |
| 썸네일 | 새 그림 (아래) |
| 언제 | 네 집을 다 올리고 **주장 확인한 뒤** |

**주장 0건인 집만 붙인다**는 규칙(`집만들기.md`)을 그대로 따른다.
네 집 중 주장이 붙은 집이 있으면 빼고 셋으로 간다(약 3시간).
억지로 넣지 않는다.

⚠️ **힙합·R&B 는 주장이 많이 붙을 가능성이 높다.** 보컬 집이 연주곡 집의
두 배 넘게 걸렸는데(012 36% · 013 46% vs 011 20% · 014 15%), 그 이유가
"유통사를 통해 스트리밍에도 내는 아티스트가 많아서" 였다
(`저작권주장.md`). 비트 메이커는 그 전형이다. **집마다 주장이 절반쯤
붙어도 놀라지 않는다.** 그래서 긴 영상은 집들을 다 올려 본 뒤에 짠다.

## 그림

(`art/그림규칙.md`).

카운터에 턴테이블이 놓인 방이다. 라운지는 012·015·018 에서 이미 세 번
썼고, 레코드 바는 아직 안 썼다. 그루브 음악과도 맞고 LP 규칙과도 맞는다.

창밖은 계절대로 — 020 은 겨울 밤 눈 내리는 도시.
