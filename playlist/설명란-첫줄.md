# 설명란 첫 줄 — 집마다

구글·유튜브 검색 결과에 보이는 것은 설명란 **첫 두 줄**이다. 7집은 외부
유입이 Google Search 100% 였는데 그 자리에 "틀어두고 하던 일을 하세요" 가
있었다. 검색어가 거기 있어야 한다.

**붙이는 법** — 설명란 맨 위에 아래 줄 + 빈 줄 한 칸을 넣는다. 나머지는 그대로 둔다.

```
공부할 때 듣는 음악 · 집중 잘 되는 조용한 음악 · 61분
                                  ← 빈 줄
눈 내린 날의 도서관에서.
틀어두고 하던 일을 하세요.
```

11집부터는 `description.mjs --lead` 가 자동으로 넣는다. 길이도 곡을 재서
스스로 붙이므로 손으로 적지 않는다.

**두 집이 같은 검색어를 쓰지 않게 했다.** 1집과 2집이 둘 다 "작업할 때
듣는 음악" 이면 검색 결과에서 서로를 밀어낸다.
