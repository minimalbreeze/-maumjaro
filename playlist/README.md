# minimalbreeze — 플레이리스트 영상

퍼블릭 도메인 음원으로 1시간짜리 재즈 플레이리스트 영상을 만든다.
유튜브 업로드는 손으로 한다 — 여기서는 영상 파일까지만 만든다.

## 효성님이 넣을 것 두 가지

### 1. 방 그림 → `art/`

Canva 에서 받은 PNG 를 `art/lobby-autumn.png` 로 넣는다.
**가로 1920px 이상**이어야 한다. 작으면 영상이 뭉갠다.

계절이 늘면 `lobby-winter.png` 처럼 옆에 더한다.

### 2. 음원 → `bgm/`

**파일을 이 폴더에 떨구기만 하면 된다.** `build.mjs` 가 폴더를 훑어
태그에서 제목·아티스트를 읽고 `목록.json` 에 알아서 적는다. 손으로 JSON 을
고칠 필요가 없다. (태그가 비어 있으면 파일 이름을 제목으로 쓴다)

적어 준 뒤 `license` 와 `source` 칸만 채워 두면 된다. 나중에 저작권 분쟁이
나면 그게 증거가 된다.

#### 어디서 받나 — 유튜브 오디오 보관함을 권한다

YouTube Studio → 왼쪽 **오디오 보관함** (https://studio.youtube.com)

| 왜 여기인가 | |
|---|---|
| **Content ID 클레임이 안 붙는다** | 이게 제일 크다. 다른 데서 받은 "무료" 음원은 누가 같은 음원을 Content ID 에 등록해 두면 클레임이 걸린다 |
| 상업 이용·수익화 허용 | |
| 큐레이션돼 있다 | archive.org 의 자유 라이선스 오디오는 팟캐스트·라디오 녹음이 대부분이라 BGM 으로 쓸 게 적다 |

**찾을 때 쓸 검색어·필터**

- 장르: `재즈` · `외국 음악` / 분위기: `차분함` · `극적인` 말고 `밝음` 도 아닌 쪽
- 길이로 거르지 말고 **들어보고** 고른다. 아래 기준으로 본다

**넣을 것**
- 느리거나 중간 템포. 발로 박자를 타게 되면 작업이 안 된다
- 악기가 적은 것. 피아노 하나, 기타 하나가 배경으로 제일 낫다
- 처음부터 끝까지 비슷한 세기. 중간에 확 커지면 놀라서 쳐다보게 된다

**뺄 것**
- 노래(보컬). 가사가 있으면 글을 못 읽는다
- 빠른 스윙·래그타임. 신나면 BGM 이 안 된다
- 드럼이 센 것

⚠️ **일부 곡은 출처 표기가 필요하다.** 받을 때 그 곡 옆에 표시가 나온다.
필요한 곡은 `목록.json` 의 `credit` 에 보관함이 알려준 문구를 **그대로** 넣는다.
그러면 설명란에 넣을 문구로 뽑아준다. 적어야 하는데 안 적으면 신고가 들어온다.

#### archive.org 에서 긁어오기 (선택)

특정 곡을 콕 집어 원할 때만 쓴다.

```bash
node playlist/scripts/fetch-music.mjs --cc --q 'jazz piano' --n 10 --dry   # 목록만
node playlist/scripts/fetch-music.mjs --pd --q 'piano' --n 10              # 1923~25 PD
```

라이선스는 코드가 거른다 — **NC(상업 금지)·ND(변경 금지)·SA(동일조건)·미표기는
받지 않는다.** 받는 것은 CC0 / 퍼블릭 도메인 / CC BY 뿐이다.

#### ⚠️ 넣기 전에 확인할 것

음원마다 **권리가 두 개**다. 둘 다 풀려야 쓸 수 있다.

| | 무엇 | 한국 기준 |
|---|---|---|
| 음반 | 그 연주를 녹음한 것 | 발행 후 70년 → 1920년대는 만료 |
| 악곡 | 그 곡을 쓴 작곡가의 권리 | **작곡가 사후 70년** |

그래서 **작곡가가 1955년 이전에 사망**해야 지금 쓸 수 있다.

| 작곡가 | 사망 | |
|---|---|---|
| 젤리 롤 모턴 | 1941 | ✅ |
| 킹 올리버 | 1938 | ✅ |
| 제임스 P. 존슨 | 1955 | ✅ (2026 만료) |
| W.C. 핸디 | 1958 | ❌ |
| 루이 암스트롱 | 1971 | ❌ |

그리고 **녹음 연도**도 봐야 한다. 같은 곡을 1926·1928년에 다시 녹음한 것이 많다.
지금 쓸 수 있는 것은 **1923~1925년 발행분**뿐이다.

전사본은 **78rpm 원반 직접 전사**를 고른다. 현대 리마스터 CD 에서 뜬 파일은
리마스터에 새 권리가 붙을 수 있고 Content ID 에도 걸린다.

> 위 표는 계산이지 법률 자문이 아니다. 수익을 낼 거면 한국저작권위원회
> 저작권상담센터(1800-5455)에 한 번 확인하는 게 맞다.

## 돌리는 법

```bash
node playlist/scripts/build.mjs                 # 그대로 만들기
node playlist/scripts/build.mjs --dry           # 계획만 출력, 렌더 안 함
node playlist/scripts/build.mjs --minutes 2     # 2분짜리로 빨리 확인
```

결과는 `out/` 에 떨어진다. 이 폴더는 커밋하지 않는다(용량).

## 음악에 하는 것 / 안 하는 것

**곡은 자르지 않는다.** 원곡의 느낌을 해치기 때문이다.

| 하는 것 | 왜 |
|---|---|
| 곡별 음량 평준화 | 78 전사본은 곡마다 음량이 제각각이다. 안 맞추면 BGM 이 안 된다 |
| 곡 사이 크래클 | 끊기지 않고 LP 한 면처럼 이어지게 |

**안 하는 것:** 대역 제한, wow&flutter, 크로스페이드, 잡음 제거.
원본이 이미 1923년 78rpm 이라 효과를 덧씌우면 LP 느낌이 아니라 지저분해진다.
MusicWeb 리뷰도 이 음원들을 "표면 잡음 처리가 조악하다"고 적었다 — 이미 충분하다.

## 영상이 지루해지지 않는 이유

움직이는 요소마다 주기를 **서로소**로 준다. 그러면 전체 패턴이 최소공배수마다
반복하므로 눈에 안 걸린다.

| 요소 주기 | 전체 반복 |
|---|---|
| 7 · 11 · 13초 | 16.7분 |
| 13 · 17 · 19초 | 70분 |

그리고 창밖은 **한 방향으로** 흐른다(해질녘 → 밤). 되돌아오지 않으므로
그 부분은 반복이 아예 없다.
