# 다 괜찮은데 67점 (참여형 · quiz)

**성격**: 참여형 — 숫자 하나를 찍게 한다
**유효 기간**: 아무 때나. 시즌 안 탄다
**감추는 것**: **결과값**. 열 문항에서 "두 번째로 좋은 답"을 전부 고르면 나오는 점수 하나를 끝까지 안 준다.
01(순위)·02(이유)·03(문장)·04(동작)·05(비교 결과)·06(빠진 것)에 없는 **일곱 번째 모양**이다.

**왜 이 조합인가**: 열 문항이 다 "나쁘지 않은" 쪽이면 80점쯤은 나올 것 같다.
그게 통념이고, 답은 67이다. 뒤집히는 자리가 **"나쁘지 않다"와 "좋다"가 다른 칸**이라는 데 있다.
답이 **숫자 하나**라 답글이 짧게 끝난다 — 길게 써야 하는 질문은 읽고 그냥 나간다.

**반박 구멍(본문 안)**: "그럼 뭘 골라야 100이냐"가 나올 자리다.
그리고 "0점이 나오는 테스트를 왜 만드냐"도 나온다. 둘 다 답글이 붙는 구멍이다.

⚠️ **"사람들은 보통 80이라고 답한다" 같은 말을 쓰지 않는다.** 확인한 적이 없다.
본문의 "넣을까 말까 했다"는 효성님 본인 얘기로 쓴다.

⚠️ **숫자를 지어내지 않는다.** 아래 숫자는 전부 `love-data.js`의 실제 가중치다.
열 문항 × 네 선택지, 가중치 +3 / +1 / -1 / -3.
전부 1번 = 30 → **100점**, 전부 2번 = 10 → **67점**,
전부 3번 = -10 → **33점**, 전부 4번 = -30 → **0점**. 50이 반반이다.
`node scripts/check-love-copy.mjs`가 이 값들을 검사한다.
