# 07 — 리포스트 아무도 안 해주더라

> 꼴: **사람 모으기 글**(스레드양식.md). 앱 얘기를 한 글자도 안 넣는다.
> 06(리포스트 부탁)의 후속이라, 앱을 또 꺼내면 광고로 읽힌다.
>
> ⚠️ "한 명도 없더라"는 **실제 결과를 보고 고칠 것.** 한두 명이 해줬으면
> "두 명 해줬다"로 바꾼다. 숫자를 지어내면 다음 글부터 안 먹힌다.

## 본문 (1/2)

```
어제 리포스트 한 번만 눌러달라고 올렸는데
한 명도 없더라 ㅋㅋㅋ

좋아요는 눌러주면서 리포스트는 안 누른다.

생각해보니 나도 안 누른다.
내 피드에 남의 글이 올라가는 게 좀 그래서.

다들 리포스트 왜 안 눌러?

#스레드 #1인개발 #인디개발
```

## 댓글 (2/2) — 본문 올리고 바로

```
좋아요는 나만 아는 거고
리포스트는 남들이 다 보는 거라 그런 것 같기도 하고.

근데 그러면 좋은 글은 어떻게 퍼지는 거지
```
