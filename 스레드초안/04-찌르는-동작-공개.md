# 찌르는 동작 공개 (참여형 · quiz) — 발행 완료 2026-09-28

**성격**: 참여형 — "뭘 것 같아?"로 맞혀보게 한다
**유효 기간**: 아무 때나. 시즌 안 탄다
**감추는 것**: **동작**. 01(순위)·02(이유)·03(문장)과 겹치지 않는 네 번째 모양이다.
**왜 이 소재인가**: 폰을 찔러서 주사를 놓는 건 이 앱에만 있는 건데
지금까지 어느 글에서도 안 썼다. 제일 특이한 걸 제일 안 쓰고 있었다.

⚠️ 본문의 "말로 들으면 좀 어이없는데"는 효성님 본인 판단으로 쓰는 말이다.
"다들 어이없어한다" 같은, 확인 안 된 남의 반응을 지어 넣지 않는다.

## 쓴 사실 (코드에서 확인)

| 쓴 말 | 근거 |
|---|---|
| 폰을 찌르듯 움직인다 | `app.js:447` 가속도 센서 기반 "찌르기" 제스처 |
| 그냥 눌러도 된다 | `app.js:838` `#arm-target` 클릭 리스너 |
| 화면 안내 문구 | `index.html:544` "콕! 찔러서 놓기 (폰을 찌르듯)" |
| 이름 뜻 | `index.html` noscript — 마운자로에서 딴 말장난, 몸이 아니라 마음에 놓는 주사 |

## 아직 안 쓴 소재 (다음 글 후보)

- 긍정 감정에도 처방이 나온다 (기쁨 2mg — "좋은 기분, 오늘 더 오래 느끼게 해드릴게요")
- 친구에게 주사를 보낼 수 있다 (공유 링크)
- 자책 문구 중 "당신을 제일 모질게 대하는 사람이 당신이에요"

### 보고 판단할 것

- **답글이 붙었나** — "뭘 것 같아?"가 추측을 유도하는 질문으로 먹혔는지.
  안 붙었으면 질문 형태를 바꾼다
- **조회수 대비 클릭이 몇 %인가** — 본문은 읽혔는데 댓글을 안 눌렀다면
  감추는 방식이 약했던 것이다
- **어느 줄에서 멈췄을까** — 답글 내용에 힌트가 있다.
  "뭔데?"류가 많으면 훅은 성공, 반응이 없으면 소재 자체가 안 걸린 것
