# 이상한 동화 — 채널 설정

> 어른도 아이도 결말을 예측할 수 없는, 짧고 기묘한 동화.
> **채널 이름은 아직 미정.**

---

## 1. 무엇을 만드는가

동화의 **형식**을 쓰되, 동화의 **결말**을 쓰지 않는다.

왕자도 용도 나오지 않는다. 대신 일상에 금이 하나 가 있고,
주인공이 그 금을 들여다보다가 **뒤집힌다.**

| | |
|---|---|
| 길이 | **4분** (3~5분) |
| 대상 | **어른.** 아동용 지정을 하지 않는다 |
| 나레이터 | 한 명. 대사를 연기하지 않고 **상황과 감정을 서술**한다 |
| 화풍 | 리소그래프 코믹스체 (아래 4번) |
| 주기 | 주 1편 |

### 아동용 지정을 안 하는 이유

YouTube Studio 에서 '아동용'을 켜면 COPPA 때문에 **맞춤 광고가 꺼지고**
댓글·저장·알림·최종화면이 전부 막힌다. 조회수가 나와도 수익 구조가 달라진다.

그래서 **어린이 동화의 형식을 빌린 어른 콘텐츠**로 간다. 이건 회피가
아니라 실제 내용이 그렇다 — 결말이 어른의 것이다.

## 2. 대본 구조 (6섹션 · 4분)

실화 미스터리의 9섹션을 쓰지 않는다. 그쪽은 조사한 사실을 쌓는 구조고,
이쪽은 **하나의 금이 벌어지는** 구조다.

| 섹션 | 하는 일 | 분량 |
|---|---|---|
| `HOOK` | 이상한 사실 **한 줄**. 설명하지 않는다 | 10초 |
| `SETUP` | 평범한 일상. **딱 한 가지만** 이상하다 | 40초 |
| `NOTICE` | 주인공이 알아챈다. 아직 무섭지 않다 | 50초 |
| `FOLLOW` | 따라가 본다. 확인하려 한다 | 60초 |
| `TURN` | 뒤집힌다. **여기가 전부다** | 40초 |
| `CLOSE` | 서늘한 여운. 설명하지 않고 끝낸다 | 20초 |

### 지켜야 할 것

- **설명하지 않는다.** 왜 그런 일이 생겼는지 끝까지 말하지 않는다.
  동화는 원래 이유를 대지 않는다 — 늑대가 왜 말을 하는지 아무도 안 묻는다
- **마지막 문장이 제일 짧다.** 길게 마무리하면 여운이 죽는다
- **교훈을 붙이지 않는다.** "그래서 우리는 ~해야 합니다" 는 금지
- 대사는 **나레이터가 전한다.** 성우가 하나뿐이라서가 아니라,
  그게 동화의 말투이기 때문이다

## 3. 1편 — 그림자가 먼저 집에 가는 아이

> 매일 저녁, 아이의 그림자는 아이보다 먼저 집에 간다.

### 비트 시트

| 섹션 | 내용 |
|---|---|
| `HOOK` | 그 동네 아이들은 해질 무렵 그림자를 먼저 보낸다. 아무도 왜인지 묻지 않는다 |
| `SETUP` | 주인공은 늘 마지막까지 논다. 해가 길어진 유월. 집에 가면 저녁상이 차려져 있고, 엄마는 늘 "왜 이렇게 늦었어" 하고 웃는다 |
| `NOTICE` | 어느 날 아이는 자기 그림자가 **반대 방향으로** 걸어가는 걸 본다. 불러도 돌아보지 않는다 |
| `FOLLOW` | 아이는 그림자를 따라간다. 그림자는 자기 집 문을 열고 들어간다. 창문 너머로 식탁이 보인다 |
| `TURN` | 그림자가 **식탁에 앉아 저녁을 먹고 있다.** 엄마가 웃으며 말한다 — "오늘은 왜 이렇게 늦었어?" 그리고 아이 쪽은 보지 않는다 |
| `CLOSE` | 아이는 문 앞에 서 있다. 해가 완전히 진다. **그림자가 없는 쪽이 밖에 남는다** |

### 왜 이걸 1편으로 쓰는가

- 썸네일이 **즉시 나온다** — 노을, 아이와 그림자가 반대로 걷는 한 장
- 제목이 곧 내용이다. 1초에 클릭 여부가 결정된다
- 등장인물이 둘(아이 + 그림자)뿐이라 **얼굴 일관성 부담이 가장 적다**
- 그림자는 대비가 강해 **AI가 실패를 잘 안 하는 소재**다

### 제목 후보

1. 그림자가 먼저 집에 가는 아이
2. 저녁마다 그림자를 먼저 보내는 마을
3. 내 그림자가 우리 집에서 밥을 먹고 있었다

### 썸네일 문구 후보 (두 줄, 각 13자 이내)

- `그림자가 먼저` / `집에 갔다`
- `식탁에 앉은 건` / `내 그림자였다`

## 4. 화풍 — 리소그래프 코믹스체

### 절대 규칙

**프롬프트에 작가 이름·작품 이름을 쓰지 않는다.**
"지브리풍", "○○ 스타일" 금지. 화풍 자체는 저작권 대상이 아니지만
특정 이름을 지목하는 순간 성격이 달라진다. **기법 용어로만 쓴다.**

### 쓰는 용어

```
risograph print texture, limited 3-color palette,
thick ink outlines, flat color blocking,
halftone shading, grainy paper, slight ink misregistration
```

### 팔레트 (3~4색 고정)

| 역할 | 색 |
|---|---|
| 먹 | 짙은 남보라 (검정 대신 — 종이 인쇄 느낌이 산다) |
| 주조 | 석양 주황 |
| 보조 | 탁한 청록 |
| 바탕 | 누런 종이 흰색 |

**매 편 같은 팔레트를 쓴다.** 편마다 바꾸면 채널이 한 덩어리로 안 보인다.

### 이게 기술적으로도 유리한 이유

사실적인 화풍일수록 컷마다 **얼굴이 다른 사람이 된다.**
리소 스타일은 얼굴 디테일이 적어서 그 문제가 훨씬 덜하다.
멋과 실리가 같은 방향인 드문 경우다.

## 5. 다음 편 후보

| 제목 | 한 줄 |
|---|---|
| 세상에서 가장 오래된 숨바꼭질 | 술래가 백 년째 세고 있다. 눈을 뜨면 세상이 끝나기 때문이다 |
| 매일 한 사람씩 잊어버리는 마을 | 아이가 벽에 이름을 적는다. 마지막 빈칸 옆엔 자기 이름이 있었다 |
| 13번째 계단 | 계단이 열두 개인 집. 밤에만 하나가 더 생긴다 |
| 이름을 파는 가게 | 이름을 팔면 소원을 들어준다. 대신 아무도 그를 부르지 못한다 |
| 내일을 훔치는 도둑 | 돈도 보석도 훔치지 않는다. 사람들의 내일을 훔친다 |
| 울음을 대신 울어 주는 가게 | 울지 못하는 사람 대신 울어 준다. 주인은 한 번도 운 적이 없다 |
| 마지막 장이 사라진 동화책 | 읽은 사람마다 결말이 다르다. 전부 자기 이야기다 |

**2편은 「세상에서 가장 오래된 숨바꼭질」이 아니라 3편에 쓴다.**
여운이 제일 긴 소재라 채널 톤이 자리 잡은 뒤에 내야 제대로 먹힌다.
