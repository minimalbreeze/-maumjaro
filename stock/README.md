# 블루칩 나침반 (`/stock/`)

50년 관점에서 존속 가능성이 높은 블루칩만 다루는 **초보자용 주식 투자 가이드**.
국내(KOSPI)와 미장(NYSE·NASDAQ)을 상단 토글로 오가며 같은 화면을 비교한다.

공개 주소: `https://maumjaro.minimalbreeze.com/stock/`

---

## 맘운자로와의 관계 — 왜 완전히 분리했나

저장소 루트의 `CLAUDE.md`는 **맘운자로를 다른 앱으로 바꾸지 않는 것**을 최상위
원칙으로 둔다. 핵심 UX는 `운 → 마음 → 처방 → 주사`이고, 모든 주요 콘텐츠는
결국 "마음의 주사"로 이어져야 한다. 주식 가이드는 그 흐름에 편입될 수 있는
콘텐츠가 아니다.

그래서 이 사이트는 맘운자로 **안에 넣지 않고 옆에 두었다**.

- 맘운자로의 `index.html` / `app.js` / `prescriptions.js` / `manifest.json` /
  `sitemap.xml` / `style.css` / 아이콘 파일 — **한 줄도 건드리지 않았다.**
- 맘운자로 홈이나 탭바에서 이 사이트로 가는 링크를 만들지 않았다.
- `localStorage` 키는 `maumjaro:stock:` 접두사를 쓴다. 맘운자로가 쓰는 기존 키를
  읽지도, 쓰지도, 지우지도 않는다.
- CSS는 브랜드 팔레트(딥틸 `#1f5c50`, 코랄~옐로 `#ff9166`→`#ffc66b`)만 재사용하고
  나머지는 독립적이다.

**별도 도메인이나 별도 저장소로 떼어내려면** `stock/` 폴더를 통째로 옮기고
`index.html`의 `og:url`·`canonical`만 새 주소로 바꾸면 된다. 다른 의존성은 없다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 껍데기. 상단 시장 토글, 4개 뷰 컨테이너, 하단 탭바, 용어 시트 |
| `stock.css` | 전체 스타일. 시장(국내/미장)에 따라 `--accent`만 딥틸↔딥인디고로 바뀜 |
| `stock-data.js` | 블루칩 유니버스(국내 13 · 미국 13), ETF, 용어 사전, 세금·계좌, 흔한 실수, 로드맵 |

## 화면 구성 (초보자가 밟아야 할 순서 = 탭 순서)

1. **진단** — 오늘의 시장 국면 5개 다이얼 → 국면 판정 → 이번 달 할 일 → 나의 성향 3문항
2. **종목** — 6축 50년 생존 점수 카드. 접었다 펴면 근거·리스크·확인 지표
3. **내 배분** — 성향 × 국면으로 계산한 코어/위성/현금 비중 + 금액 환산 + 실행 규칙 + 3개월 로드맵
4. **배우기** — 향후 10년 구조적 테마, 뉴스 판단 3문항, 흔한 실수 8가지, 세금·계좌, 용어 사전

종목 고르기(2번)보다 **나와 시장을 아는 것(1번)** 이 앞에 오는 순서다.

## 핵심 설계: "시황을 적지 않고 판정 규칙을 넣었다"

빌드도 서버도 없는 정적 사이트에 오늘의 시황을 문장으로 적어 넣으면,
배포한 다음 날부터 틀린 정보가 된다. 정세는 하루 만에 뒤집히는데 파일은
그대로 있는 게 가장 위험하다 — 초보자는 그 낡은 문장을 최신 정보로 믿는다.

그래서 시황을 **적어주는** 대신 **판정 규칙**을 넣었다.

```
사용자가 5개 다이얼을 오늘 값으로 맞춤 (각 30초, 확인 링크 제공)
        ↓
market-context.js 의 규칙 엔진
        ↓
국면 라벨 + 근거 해설 + 배분 조정(%p) + 이번 달 행동
```

다이얼은 **금리 방향 · 경기 · 밸류에이션 · 원/달러 환율 · 지정학 긴장도** 5개다.
파일이 낡아도 결과는 항상 오늘 기준이 되고, 덤으로 초보자가 "무엇을 봐야
하는지"를 배운다 — 이 사이트가 사라져도 남는 능력이다.

배분 조정은 **비대칭**으로 설계했다. 위험을 키우는 방향(+위성)보다 줄이는
방향(+현금)의 절댓값이 크다. 초보자에게는 기회를 놓치는 것보다 크게 다치는
쪽이 훨씬 비싸기 때문이다.

### 기준일 관리

`market-context.js`의 `DEFAULTS.asOf`는 **사람이 마지막으로 확인한 날짜**다.
앱이 이 날짜와 오늘을 비교해 며칠 지났는지 화면 최상단에 크게 띄우고,
오래됐으면 경고를 띄운다. 사용자가 다이얼을 한 번이라도 만지면 그 날짜가
`maumjaro:stock:touched`에 저장되고 이후로는 그 날짜를 기준으로 센다.

**기본값을 갱신할 때는 `asOf`도 반드시 같이 고칠 것.**

```js
var DEFAULTS = {
  asOf: '2026-05-31',        // ← 여기를 같이 고친다
  kr: { rates: 'hold', growth: 'slow', valuation: 'cheap', fx: 'weak', geo: 'tense' },
  us: { ... }
};
```

## 데이터를 고칠 때 지킬 것

### `stock-data.js`에 넣어도 되는 것 / 안 되는 것

| 넣는다 | 넣지 않는다 |
|---|---|
| 사업 구조, 해자의 성격 | 주가, 시가총액 |
| 배당 정책의 역사 | PER, PBR, 배당수익률 |
| 규제·지정학 노출 | 분기 실적 수치 |
| 확인해야 할 지표의 **이름** | 그 지표의 **현재 값** |

정적 사이트에 숫자를 하드코딩하면 그 순간부터 틀린 값이 되고, 초보자는 그걸
믿는다. 대신 각 종목의 `check` 배열로 "직접 확인할 지표"를 주고, 각 시장의
`sources`로 원자료 링크(DART·KRX·한국은행 / SEC EDGAR·FRED·FedWatch)를 준다.

### 점수는 정성 평가다

6축(수요 지속성·해자·재무 체력·현금창출력·주주환원 지속성·지정학 내성)을
0~5로 매긴 **주관적 평가**이며 투자 추천이 아니다. UI에도 그렇게 표시된다.
점수를 올리거나 내릴 때는 근거(`why`)와 리스크(`risk`)를 같이 고칠 것.

평가하는 질문은 **"50년 뒤에 얼마나 오를까"가 아니라 "50년 뒤에도 있을까"** 다.
존속 가능성과 수익률은 다른 질문이고, 이 사이트는 전자만 다룬다.

### 종목을 추가할 때

`tag`는 셋 중 하나:

- `core` — 흔들려도 팔지 않을 뼈대
- `income` — 배당 중심
- `satellite` — 변동이 커서 작은 비중으로만 다룰 것

`satellite`로 분류한 종목은 "내 배분" 화면에서 위성 슬롯에만 들어가고,
카드에 빨간 태그가 붙는다.

## 저장 키

전부 `maumjaro:stock:` 접두사. 이 브라우저에만 남고 서버로 전송되지 않는다.

| 키 | 내용 |
|---|---|
| `maumjaro:stock:market` | 마지막으로 본 시장 (`kr` / `us`) |
| `maumjaro:stock:regime` | 시장별 다이얼 상태 |
| `maumjaro:stock:profile` | 투자 기간·감내도·월 투자금·환율 |
| `maumjaro:stock:touched` | 다이얼을 마지막으로 만진 날짜 |
| `maumjaro:stock:agreed` | 첫 고지 확인 여부 |

"배우기 → 값을 되돌리기"는 **위 키만** 지운다. 맘운자로의 기록에는 손대지 않는다.

## 고지

이 사이트는 **투자 교육 자료**다. 특정 종목의 매수·매도를 권유하지 않고
어떤 수익도 보장하지 않는다. 세법·세율·한도는 매년 바뀌므로 실제 신고 전에는
국세청·증권사에서 확인해야 한다. 이 문구는 첫 방문 배너, "배우기" 탭 하단,
"내 배분" 결과 아래 세 곳에 반복해서 노출된다 — **줄이거나 없애지 말 것.**
