# 스포츠 뉴스 → 워드프레스 임시글 자동화

최신 스포츠 뉴스를 모아 사실을 확인하고, 워프양식으로 글을 쓴 뒤
**워드프레스에 임시글(draft)로만** 저장합니다.

> **자동 발행은 하지 않습니다.**
> 저장된 글은 관리자 화면의 "임시글"에만 들어갑니다. 방문자에게도 검색엔진에도
> 보이지 않습니다. 사장님이 직접 열어보고 "공개하기"를 눌러야 발행됩니다.

---

## 1. 설치 (처음 한 번만)

### 준비물
- Node.js 22 이상 — https://nodejs.org 에서 LTS 버전 설치
- Claude API 키 — https://console.anthropic.com
- 워드프레스 애플리케이션 비밀번호 (아래 설명)

### 설치

```bash
cd sports-news
npm install
```

### 애플리케이션 비밀번호 만들기

로그인 비밀번호를 쓰는 게 아닙니다. 별도로 발급받습니다.

1. 워드프레스 관리자 접속
2. **사용자 → 프로필** 메뉴
3. 페이지 맨 아래 **"애플리케이션 비밀번호"** 항목
4. 이름 칸에 `sports-news` 처럼 아무거나 입력 → **새 애플리케이션 비밀번호 추가**
5. `abcd efgh ijkl mnop qrst uvwx` 형태의 값이 나옵니다. **이 창을 닫으면 다시 볼 수 없으니 바로 복사하세요.**

> 이 항목이 안 보이면 사이트가 https가 아니거나 보안 플러그인이 막고 있는 경우입니다.

### .env 파일 만들기

```bash
cp .env.example .env
```

`.env` 파일을 메모장으로 열어 4개 값을 채웁니다.

```
ANTHROPIC_API_KEY=sk-ant-...
WORDPRESS_URL=https://내블로그주소.com
WORDPRESS_USERNAME=내아이디
WORDPRESS_APP_PASSWORD=abcd efgh ijkl mnop qrst uvwx
```

띄어쓰기는 그대로 두셔도 됩니다. 프로그램이 알아서 처리합니다.

## 2. 사이트 조사 (처음 한 번, 그리고 카테고리가 바뀔 때마다)

```bash
npm run wp:check
```

**글을 만들지 않습니다.** 사이트를 읽기만 합니다. 확인하는 것:

- 실제 카테고리 목록과 각각의 ID
- 발행된 글 수
- SEO 플러그인(Rank Math / Yoast)이 있는지
- **REST API로 SEO 제목·설명을 저장할 수 있는지**

마지막 항목이 중요합니다. 워드프레스는 등록되지 않은 meta 필드를 조용히 무시하기
때문에, 확인 없이 저장을 시도하면 "저장했다고 나오는데 실제로는 비어 있는" 상태가
됩니다. 그래서 먼저 사이트가 직접 신고하는 스키마를 읽어 확인합니다.

결과는 `config/site.json`에 저장되고, 이후 실행에서 자동으로 쓰입니다.

### SEO 필드가 "쓸 수 없음"으로 나오면

정상입니다. Rank Math는 기본 설정에서 REST 쓰기를 열어두지 않습니다. 두 가지 선택지가 있습니다.

**(A) 그냥 쓰기** — SEO 제목·설명이 `out/` 폴더의 파일에 남습니다. 임시글을 편집할 때
복사해서 Rank Math 칸에 붙여넣으시면 됩니다. 글 하나당 10초쯤 걸립니다.

**(B) 필드 열기** — 워드프레스 테마의 `functions.php`에 아래를 추가하면 자동 저장됩니다.
(테마 업데이트 시 지워지므로 자식 테마나 코드 스니펫 플러그인 사용을 권합니다.)

```php
add_action('init', function () {
  foreach (['rank_math_title', 'rank_math_description', 'rank_math_focus_keyword'] as $key) {
    register_post_meta('post', $key, [
      'show_in_rest'  => true,
      'single'        => true,
      'type'          => 'string',
      'auth_callback' => function () { return current_user_can('edit_posts'); },
    ]);
  }
});
```

추가한 뒤 `npm run wp:check`를 다시 돌리면 "쓸 수 있음"으로 바뀝니다.

## 3. 실행

### 먼저 테스트 (워드프레스에 아무것도 저장 안 됨)

```bash
npm run news -- --dry-run
```

전체 종목을 돌며 글을 만들고 `out/날짜/` 폴더에 파일로만 저장합니다.
한 종목만 보려면:

```bash
npm run news -- --topic="JLPGA" --dry-run
```

### 마음에 들면 실제 임시글로 저장

```bash
npm run news -- --topic="JLPGA" --draft
```

실행이 끝나면 편집 링크가 화면에 나옵니다. 그 링크를 열어 확인하고 발행하시면 됩니다.

> **`--draft`를 붙이지 않으면 절대 저장되지 않습니다.** 기본값이 "저장 안 함"입니다.

### 그 외 옵션

| 명령 | 설명 |
|---|---|
| `--topic="KBO"` | 한 종목만. 여러 번 쓰면 여러 종목 |
| `--limit=3` | 한 종목에서 글 3개까지 |
| `--dry-run` | 저장 안 함 (기본값) |
| `--draft` | 워드프레스 임시글로 저장 |

## 4. 설정 바꾸기

### 종목 추가·삭제 — `config/topics.json`

항목 하나를 복사해서 붙여넣고 고치면 됩니다.

```json
{
  "name": "테니스",
  "enabled": true,
  "category": "스포츠",
  "queries": ["테니스 그랜드슬램", "ATP 투어"],
  "longTermHints": ["대회 일정", "랭킹"]
}
```

- `enabled`를 `false`로 하면 그 종목은 건너뜁니다
- `category`는 워드프레스 카테고리 이름. 없는 이름이면 "스포츠"로 들어갑니다
- `longTermHints`는 이 단어가 들어간 뉴스에 가점을 줍니다

### 글투 바꾸기 — `config/style-warp.md`

이 파일이 Claude에게 그대로 전달되는 글쓰기 지시서입니다.
문체나 구조를 바꾸고 싶으면 **이 파일만 고치면 됩니다.** 코드는 건드릴 필요 없습니다.

### 수집 범위 — `config/topics.json`의 `defaults`

| 항목 | 뜻 | 기본값 |
|---|---|---|
| `hoursWindow` | 몇 시간 이내 기사만 볼지 | 72 |
| `minSources` | 최소 몇 개 매체가 다뤄야 글감으로 볼지 | 2 |
| `maxItemsPerQuery` | 검색어 하나당 최대 기사 수 | 25 |

`minSources`를 1로 낮추면 글감은 늘지만, 한 매체의 단독 보도를 사실처럼 쓸
위험이 생깁니다. 2 이상을 권합니다.

## 5. 이 프로그램이 지키는 것

**사실**
- 기사 원문을 저장하거나 재게시하지 않습니다. 제목·요약·링크·날짜만 참고합니다
- 2개 이상 매체가 다룬 사건만 글감이 됩니다
- 웹검색으로 일정·장소·상금·중계를 교차 확인하고, **확인된 것만** 본문에 씁니다
- 확인 못 한 정보는 그 문장을 아예 빼버립니다. 지어내지 않습니다
- 확인된 사실이 3건 미만이면 글을 만들지 않습니다

**중복**
- 기존 글과 제목이 75% 이상 비슷하고 최근 글이면 → 만들지 않습니다
- 비슷하지만 30일 넘게 지났으면 → "기존 글 업데이트 후보"로 표시합니다
- 애매한 구간(35~75%)은 AI가 실제 내용을 보고 판단합니다

**안전**
- API 키와 비밀번호는 `.env`에만 있고, 화면·로그 어디에도 찍히지 않습니다
- 저장 상태는 `draft` 상수로 고정되어 있고 인자로 바꿀 수 없습니다
- 저장 후 워드프레스가 돌려준 상태가 `draft`가 아니면 즉시 오류를 냅니다
- 카테고리를 새로 만들지 않습니다

## 6. 문제가 생기면

| 증상 | 원인과 해결 |
|---|---|
| `인증 실패(401)` | 애플리케이션 비밀번호가 틀렸습니다. 새로 발급받아 `.env`에 다시 넣으세요. 아이디에 이메일을 넣으셨다면 로그인 아이디로 바꿔보세요 |
| `권한 없음(403)` | 그 계정에 글 작성 권한이 없습니다 |
| `워드프레스가 아닌 곳에서 403 응답` | 요청이 워드프레스까지 닿지 못했습니다. 보안 플러그인(Wordfence 등)·Cloudflare·호스팅 방화벽이 REST API를 막은 경우입니다. 메시지 괄호 안에 어디서 막혔는지 나옵니다 |
| `경로를 찾을 수 없음(404)` | `WORDPRESS_URL`을 확인하세요. 끝에 `/`를 빼야 합니다 |
| `글감 후보가 없습니다` | 정상일 수 있습니다. 최근 72시간 안에 2개 매체가 다룬 뉴스가 없다는 뜻입니다. `hoursWindow`를 168(일주일)로 늘려보세요 |
| `확인된 사실이 부족합니다` | 의도된 동작입니다. 근거 없이 글을 만들지 않습니다 |
| `피드 응답 403` | 구글뉴스가 일시적으로 막은 경우입니다. 잠시 후 다시 실행하세요 |

로그는 `../logs/날짜.log`에 남습니다. 비밀번호는 자동으로 가려집니다.

## 7. 폴더 구조

```
sports-news/
 ├ config/
 │   ├ topics.json       종목·검색어          ← 자주 고치는 파일
 │   ├ style-warp.md     글쓰기 규칙          ← 자주 고치는 파일
 │   └ site.json         wp:check 결과 (자동 생성)
 ├ src/
 │   ├ main.mjs          전체 실행 흐름
 │   ├ news/             RSS 수집·군집화·점수
 │   ├ ai/               사실확인·작성·SEO
 │   ├ duplicate/        중복 검사
 │   ├ wordpress/        REST 클라이언트·임시글 저장
 │   └ utils/            로그·환경변수·재시도
 ├ test/                 오프라인 검증
 ├ out/                  생성된 글 (깃에 안 올라감)
 └ .env                  비밀 값 (깃에 안 올라감)
```

이 폴더는 자기완결형입니다. 나중에 다른 저장소로 통째로 옮겨도 그대로 동작합니다.
