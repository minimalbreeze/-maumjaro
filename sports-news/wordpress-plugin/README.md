# Rank Math SEO 칸을 REST로 여는 플러그인

## 이게 뭔가요

자동화가 워드프레스에 임시글을 만들 때, **SEO 제목·메타 설명·대표 키워드** 칸이
비어 있는 문제를 해결합니다.

워드프레스 REST API는 미리 등록된 meta만 저장을 허용합니다. Rank Math는 자기 칸을
REST에 열어두지 않기 때문에, 밖에서 글을 만들면 본문·카테고리·태그는 들어가지만
SEO 칸은 빈 채로 남습니다. 이 플러그인은 **그 세 칸만** REST에 엽니다.

## 설치 방법 (한 번만 하면 됩니다)

1. `maumjaro-seo-rest.zip` 파일을 받습니다.
2. 워드프레스 관리자 → **플러그인** → **새로 추가** → **플러그인 업로드**
3. zip 파일을 고르고 **지금 설치**
4. **플러그인 활성화**

## 설치했는지 확인하는 방법

GitHub Actions에서 워크플로를 한 번 돌리면 `사이트 조사` 단계에 이렇게 나옵니다.

설치 전:
```
⚠️  REST로 쓸 수 있는 SEO 메타 필드가 없습니다.
```

설치 후:
```
✅ SEO 메타 필드 3개를 REST로 쓸 수 있습니다
     rank_math_title, rank_math_description, rank_math_focus_keyword
```

이 메시지가 보이면 그때부터 임시글에 SEO 칸이 자동으로 채워집니다.

## 안전한가요

- 여는 것은 위 세 개뿐입니다. 다른 meta는 건드리지 않습니다.
- 글을 수정할 권한이 있는 로그인 사용자만 쓸 수 있습니다.
- 값은 문자열로만 받고 저장 전에 정리합니다.
- 기존 데이터를 바꾸거나 지우지 않습니다. 플러그인을 지워도 이미 저장된 SEO 값은 남습니다.
