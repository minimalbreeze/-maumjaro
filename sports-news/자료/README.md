# 자료 — 글을 쓰기 전에 모아둔 사실들

## 왜 이 폴더가 있나

2026-10-09 에 란커배 글을 쓰다가 **결과물 없이 412원을 날렸다.** 사실 확인
단계가 웹검색을 다 태우고도 1차 출처를 하나도 확정하지 못해 작성을 거부했다.

그런데 그 재료는 각도를 정하려고 돌린 검색에 이미 다 있었다. **모아두지
않아서 다시 못 쓴 것이다.**

그래서 글을 쓰기 전에 모은 사실을 여기 파일로 남긴다. 채팅으로만 주고받으면
다음에 같은 글감을 다시 할 때 찾을 수가 없다(리포 지시서의 초안 규칙과 같은
이유다).

## 쓰는 법

`--article=<이 폴더의 파일>` 로 넘긴다. 워크플로에서는 `기사 본문을 붙여넣기`
칸에 내용을 붙인다. 뉴스 수집과 맨손 검색을 건너뛰므로 **입력 토큰이 크게
떨어진다**(실측 83,940 → 25,822).

## 적는 법

- **항목마다 출처를 적는다.** 어디서 온 사실인지 모르면 쓸 수 없다.
- **교차 확인이 안 된 것은 `【미확인】`을 붙인다.** 그 표시가 있으면 작성
  단계가 사실로 쓰지 않는다. 지어낸 숫자가 글에 들어가는 것을 막는 장치다.
- 기사 원문을 그대로 옮겨 적지 않는다. 확인된 사실만 항목으로 정리한다.
- 숫자가 출처마다 다르면 **다르다는 사실까지 적는다**(예: 환율 환산액).
