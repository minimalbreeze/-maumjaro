# 안내 줄 넣기 — 왜 이 도구가 있나

시즌이 바뀌면 작년 글과 올해 글이 같은 검색어로 경쟁한다.

실제로 이렇게 됐다.

```
2905  2025-26 KBL 경기일정·중계 어디서 보나   ← 노출 762 / 클릭 1
7690  2026-27 KBL 경기일정·중계 어디서 보나   ← 새로 쓴 글
```

작년 글은 이미 검색결과에 올라가 있고 노출을 받는다. 그런데 사람들이 찾는 건
올해 일정이다. 작년 글에 들어온 사람은 날짜가 안 맞으니 그냥 나간다.

작년 글을 지우면 그 순위를 통째로 버리게 된다. 그래서 **지우지 않고, 맨 위에
올해 글로 가는 한 줄을 넣는다.** 들어온 사람을 올해 글로 흘려보내는 것이다.

```
📅 2026-27 시즌 일정·중계는 여기로 → (링크)
```

## 쓰는 법

```
npm run notice -- 2905 --text="2026-27 시즌 일정·중계는 여기로" --url="https://..." --dry-run
npm run notice -- 2905 --text="..." --url="..."
```

## 지키는 것

- 본문 맨 위에 한 블록만 넣는다. 그 밖의 글자는 건드리지 않는다.
- 같은 안내가 이미 있으면 다시 넣지 않는다(두 번 돌려도 안전하다).
- 링크는 현재 창에서 연다. 내 블로그 안으로 가는 링크라 nofollow 를 붙이지 않는다.
- 고치기 전 원본 본문을 파일로 남긴다.
- content 하나만 보낸다. 제목·슬러그·발행상태는 보내지 않는다.
