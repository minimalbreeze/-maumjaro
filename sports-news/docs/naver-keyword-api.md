# 네이버 검색 신호 붙이기

글감을 고를 때 **추정이 아니라 네이버가 집계한 숫자**를 보게 만듭니다.
길이 두 가지인데, **A만 해도 충분합니다.**

| | A. 데이터랩 검색어트렌드 | B. 검색광고 키워드도구 |
|---|---|---|
| 주는 것 | 관심 **추이** (0~100 상대지수) | **월간 검색수** (절대값) |
| 필요한 것 | 네이버 아이디 | 광고 계정 (막힐 수 있음) |
| 사업자등록 | 필요 없음 | 개인도 되지만 거절될 수 있음 |
| 비용 | 무료 | 무료 |

둘은 역할이 다릅니다. **"올라오는 중인가"는 A**, **"얼마나 큰가"는 B**입니다.
A만 있어도 "관심이 올라오는 주제"는 고를 수 있습니다.

---

## A. 데이터랩 검색어트렌드 (권장 · 5분)

### 1. 앱 등록

1. https://developers.naver.com/apps/#/register 접속 → 네이버 아이디로 로그인
2. **애플리케이션 이름**: 아무거나 (예: `스포츠뉴스 트렌드`)
3. **사용 API**: **데이터랩 (검색어트렌드)** 선택
4. **환경 추가**: `WEB 설정` 고르고 서비스 URL에 `https://wiki.minimalbreeze.com` 입력
5. **등록하기**

### 2. 키 두 개 복사

등록하면 바로 나옵니다.

| GitHub에 넣을 이름 | 네이버 화면 이름 |
|---|---|
| `NAVER_CLIENT_ID` | Client ID |
| `NAVER_CLIENT_SECRET` | Client Secret |

데이터랩 키는 나중에 다시 볼 수 있습니다(내 애플리케이션 → 해당 앱).

### 3. GitHub에 넣기

리포 → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**
위 두 이름으로 각각 등록합니다.

---

## B. 검색광고 키워드도구 (선택)

절대 검색수까지 보고 싶을 때만 합니다. **안 돼도 괜찮습니다.**

1. https://searchad.naver.com 가입 → **개인 광고주** 선택
2. **내 정보 → 도구 → API 사용 관리 → 등록**
3. 세 값을 GitHub 시크릿으로:
   `NAVER_AD_API_KEY`(액세스라이선스) · `NAVER_AD_SECRET`(비밀키) · `NAVER_AD_CUSTOMER_ID`

**비밀키는 그 화면에서만 보입니다.** 창을 닫으면 다시 못 봅니다.

### "플랫폼 이용이 제한된 대상으로 광고 계정 생성이 불가합니다"가 나오면

네이버가 그 계정의 광고주 가입을 막은 것입니다. 왜인지는 공개 문서에 없어서
네이버 고객센터에 물어봐야 알 수 있습니다. **이 길은 포기하고 A만 쓰면 됩니다.**
A만 있어도 글감 고르기는 동작합니다.

## 되는지 확인

```
npm run keywords -- 박신자컵 여자농구 WKBL
```

```
📈 최근 30일 검색 추이 (0~100 상대지수 — 이 목록 안에서만 비교됩니다)
⭐ 박신자컵          지수  72  상승 중 (최근이 평소의 6.1배)
   여자농구          지수  45  평탄
  ⭐ = 관심이 올라오는 중 — 지금 쓰면 좋은 주제
```

글을 만들 때는 후보 목록에 이렇게 찍힙니다.

```
후보 12개 중 1개 목표 (데이터랩 추이 반영)
  1. [46점] 박신자컵 10월 3일 개막 · "박신자컵" 상승 6.1배/지수 72
  2. [12점] 아시안게임 여자농구 결승 · "아시안게임" 평탄/지수 95
```

## 상대지수를 검색수로 착각하지 마세요

데이터랩의 0~100은 **그 요청에 함께 넣은 키워드들 사이의** 상대값입니다.
"지수 72"는 월 72회가 아니고, 다른 날 다른 묶음으로 조회한 숫자와 비교해도
의미가 없습니다. 코드도 이 둘을 섞지 않습니다.

## 왜 큰 숫자가 꼭 좋은 게 아닌가

검색이 아주 많은 키워드는 1페이지를 언론사와 대형 사이트가 채웁니다.
개인 블로그가 비집고 들어갈 자리는 **적당한 크기 + 경쟁 낮음 + 관심 상승** 구간입니다.
점수표도 그렇게 매깁니다.

## 안 되면

- **401** → 키가 틀렸습니다. 앞뒤 공백을 확인하세요.
- **403** → 그 앱에 "데이터랩(검색어트렌드)" API가 추가돼 있는지 확인하세요.
- **429** → 너무 자주 불렀습니다. 잠시 뒤 다시.

키가 없어도 글은 그대로 만들어집니다. 기사 쏠림 신호로 글감을 고릅니다.
