# 네이버 검색광고 API 키 발급받기 (무료, 한 번만)

이 키가 있으면 글감을 고를 때 **추정이 아니라 네이버가 집계한 실제 월간 검색수**를
봅니다. 광고를 집행하지 않아도 발급됩니다. 비용은 없습니다.

## 1. 검색광고 가입

1. https://searchad.naver.com 접속 → 네이버 아이디로 로그인
2. 안내에 따라 가입 (사업자 없이 **개인**으로도 됩니다)
3. **광고를 만들거나 돈을 넣을 필요는 없습니다.** 가입만 하면 됩니다.

## 2. 키 세 개 받기

1. 오른쪽 위 **내 정보** → **도구** → **API 사용 관리**
2. **네이버 검색광고 API 라이선스** 화면에서 **등록** 버튼
3. 화면에 나오는 값 세 개를 적어둡니다.

| 적어둘 것 | 화면 이름 | 생김새 |
|---|---|---|
| `NAVER_AD_API_KEY` | 액세스라이선스 | `0100000000...` 긴 문자열 |
| `NAVER_AD_SECRET` | 비밀키 | `AQAAAAA...` 긴 문자열 |
| `NAVER_AD_CUSTOMER_ID` | CUSTOMER ID | `1234567` 숫자 |

**비밀키는 그 화면에서만 보입니다.** 창을 닫으면 다시 못 봅니다. 꼭 복사해 두세요.

## 3. GitHub에 넣기

리포 → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**

세 번 반복합니다 (이름은 위 표의 왼쪽 그대로, 값은 복사한 것):

- `NAVER_AD_API_KEY`
- `NAVER_AD_SECRET`
- `NAVER_AD_CUSTOMER_ID`

## 4. 되는지 확인

워크플로를 **"사이트 조사만 (비용 0원)"** 으로 한 번 돌리면 로그에 나옵니다.
글을 만들 때는 후보 목록에 이렇게 찍힙니다.

```
후보 12개 중 1개 목표 (네이버 검색수 반영)
  1. [46점] 박신자컵 10월 3일 개막 · "박신자컵" 월 8,100회/경쟁 낮음
  2. [12점] 아시안게임 여자농구 결승 · "아시안게임" 월 246,000회/경쟁 높음
```

내 PC에서 직접 찾아볼 수도 있습니다.

```
npm run keywords -- 박신자컵 여자농구 WKBL
```

## 왜 큰 숫자가 꼭 좋은 게 아닌가

월 246,000회짜리 키워드는 검색결과 1페이지를 언론사와 대형 사이트가 채웁니다.
개인 블로그가 비집고 들어갈 자리는 **월 1,000~30,000회 + 경쟁 낮음** 구간입니다.
점수표도 그렇게 매깁니다. `npm run keywords`에서 ⭐ 표시가 그 구간입니다.

## 안 되면

- **401 인증 실패** → 세 값 중 하나가 틀렸습니다. 특히 비밀키 앞뒤 공백을 확인하세요.
- **403 권한 없음** → 라이선스를 다시 등록해 보세요.
- **429** → 너무 자주 불렀습니다. 잠시 뒤 다시.

키가 없어도 글은 그대로 만들어집니다. 검색수 대신 기사 쏠림 신호로 글감을 고릅니다.
