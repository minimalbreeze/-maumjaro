# 검증: 돈은 틈새에서 나오는가

운영자 가설(2026-10-04): **"어차피 돈은 틈새에서 나온다."**
큰 키워드는 네이버 블로그·뉴스가 다 먹으므로, 아무도 제대로 쓰지 않은 작은
키워드에서 수익이 난다는 것.

## 먼저 밝혀진 사실 — 유입은 네이버다

2026-10-04 측정:

```
wiki.minimalbreeze.com — 검색 인덱스에 잡힌 키워드 0개
"남서울CC 파3 골프장" 구글 1페이지(1~9위)에 이 블로그 없음
  → 1위 nscc.co.kr(공식) · 네이버 블로그 2개 · 네이버 프리미엄 1개
    · 김캐디 1개 · 유튜브 2개
```

그런데 운영자는 그 글의 노출·클릭이 많다고 한다. **구글에서는 거의 안 잡히는데
유입이 있다 = 네이버 유입이다.**

이게 중요한 이유: 지금까지의 최적화는 전부 구글 기준이었다(Rank Math 점수,
구글 색인 3~14일, 구글 SERP, 구글 검색량). 돈이 들어오는 입구는 네이버다.
네이버는 C-Rank·D.I.A.로 돌고 자사 블로그를 우대한다 — 워드프레스는 구조적으로
불리하다. **그래서 틈새가 유일한 통로라는 가설이 설득력을 얻는다.**

판단에 쓸 나침반은 `config/search-demand.md`(네이버 서치어드바이저 실측)다.
OpenRush로 뽑는 구글 검색량·검색 의도는 **참고**다. 둘을 섞어 쓰지 않는다.

## 왜 두 글 비교가 안 됐나

운영자가 신지애 글 두 개(대회명+결과 / 상금+기록)를 비교하자고 했다. 그런데
두 번째 글이 **중복 판정으로 건너뛰어졌다**(4원).

```
AI 중복 판정: 동일한 사건(같은 날짜, 같은 대회, 같은 30승·커리어 그랜드슬램)
```

같은 소재 두 글은 같은 검색어로 경쟁한다(카니발라이제이션). 구글·네이버가 둘 중
하나만 올리므로, 비교 결과가 "어느 각도가 맞나"가 아니라 "누가 상대를 밀어냈나"가
된다. **코드가 이걸 막은 판단이 옳다.** 억지로 썼으면 둘 다 밀렸다.

## 그래서 이렇게 비교한다 — 다른 소재, 다른 유형

| | A | B |
|---|---|---|
| 글 번호 | 7769 | (B 생성 후 적는다) |
| 제목 | 신지애 … JLPGA 통산 30승, 커리어 그랜드슬램 | 서울 근교 파3 골프장 추천·이용료 |
| 유형 | 기록형 | 구매의도형 |
| 검색 의도 | informational | commercial / transactional |
| 키워드 크기 | 큼 (신지애 월 2,400, 우승 시 8,100까지) | 작음 (파3 골프장 추천 110 · 서울 근교 80) |
| 경쟁 | 네이버 블로그·뉴스가 다 먹는다 | **LOW — 비어 있다** |
| 글감 점수 | 106점 | 160점 (구매의도 가점 반영 후) |

소재가 다르므로 서로 잡아먹지 않는다.

## 측정 (운영자가 채운다)

네이버 서치어드바이저 기준. 구글 서치콘솔도 있으면 함께.

| 시점 | 글 | 노출 | 클릭 | CTR | 들어온 검색어 1~3위 | 광고 클릭 | 수익 |
|---|---|---|---|---|---|---|---|
| 1주 (10/11) | A 7769 | | | | | | |
| 1주 (10/11) | B | | | | | | |
| 1개월 (11/4) | A 7769 | | | | | | |
| 1개월 (11/4) | B | | | | | | |

## 가설과 판정 기준

- **가설 1 (수명)**: A는 1주 뒤 노출이 급감하고, B는 1개월 뒤에도 유지된다.
  → A의 1개월 노출이 1주의 절반 미만이고 B가 1주 수준을 유지하면 가설 성립.
- **가설 2 (틈새가 돈이 된다)**: B의 노출이 A보다 적어도 **광고 클릭은 B가 많다.**
  → 운영자 가설의 핵심. 이게 맞으면 점수표의 구매의도 가점을 더 올린다.
- **가설 3 (경쟁 밀도)**: 경쟁 LOW인 B가 상위에 오르고, 경쟁 심한 A는 안 오른다.
  → 들어온 검색어 목록으로 본다. A에 "신지애" 단독 검색이 없으면 큰 키워드에서
    밀린 것이다.

가설 2가 깨지면(B도 클릭이 안 나오면) 문제는 글감이 아니라 **광고 자리·종류**다.
그때는 글을 더 쓰지 않고 광고 쪽을 본다.

도메인을 제대로 커버하지 못할 수 있다**(신뢰도 0.5, "live SERP보다 늦을 수
있음"). 네이버 수치가 1차 근거다.

## 섞어 쓰지 말 것

- 광고를 동시에 손대지 않는다. 글감 효과와 광고 효과가 섞이면 둘 다 모른다.
- `target="_blank"` 수정(2026-10-04)은 이 기간에 걸쳐 있다. 전면 광고 복구
  효과가 두 글에 **공통으로** 걸리므로 A·B 비교에는 영향이 적지만, 수익
  절대값은 그 때문에 올라갈 수 있다. `config/revenue.md`에 따로 적는다.
