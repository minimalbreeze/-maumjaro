# 참조 얼굴

그림에 나올 사람의 **얼굴만** 잘라 둔 곳이다.

## 왜 있나

글로만 생김새를 적으면 "그 조건에 맞는 아무 얼굴"이 나온다. 3·5화에서
김도영도 노시환도 샷마다 다른 남자였다. 참조 모델(`portrait`)은 사진에서
얼굴 특징을 직접 가져오므로 진짜로 닮는다.

**사람당 한 장이면 된다.** 동작·각도·배경은 샷마다 프롬프트로 만든다.
타석에 선 그림, 더그아웃에 앉은 그림, 전신 그림이 다 이 한 장에서 나온다.
샷마다 사진을 구할 필요가 없다.

## 왜 얼굴만 잘라 두나

1. 참조 모델이 **얼굴만 본다**(`main_face_image`). 유니폼·배경·관중은
   안 쓴다. 넣어 봐야 쓰지 않는 것을 공개 저장소에 올리는 셈이다.
2. 얼굴이 크게 들어갈수록 결과가 더 닮는다. 원본에서 얼굴이 작으면
   모델이 특징을 덜 가져간다.

## 어떻게 쓰나

`스포츠영상/N화.json` 의 `people[].photo` 에 **공개로 받을 수 있는 주소**를
적는다. 이 폴더의 파일은 이렇게 쓴다.

```
https://raw.githubusercontent.com/minimalbreeze/-maumjaro/main/ai-surprise/reference-faces/<파일이름>
```

⚠️ **GitHub 첨부 주소(`github.com/user-attachments/...`)는 안 된다.**
2026-11-04 에 그걸로 돌렸다가 Replicate 이 404 로 못 읽었다(실행 #53).
그 주소는 공개가 아니다. 저장소에 들어 있는 파일만 된다.

⚠️ 파일 이름은 **영문자만** 쓴다. 한글 이름은 주소에서 깨진다.

안 닮지만 죽지는 않는다. 없는 주소를 적어 두면 그 샷이 통째로 실패한다.
