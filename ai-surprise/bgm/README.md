# 배경음악

유튜브 오디오 보관함에서 받은 곡을 여기에 넣습니다.
저작권이 안전하고 공짜입니다.

## 받는 곳

YouTube Studio → 왼쪽 메뉴 **오디오 보관함**
https://studio.youtube.com → 오디오 보관함

## 고르는 기준

이 채널은 미스터리 다큐 톤입니다. 다음을 피하세요.

- 멜로디가 분명한 곡 — 나레이션과 싸웁니다
- 드럼이 센 곡 — 긴장이 아니라 소음이 됩니다
- 밝은 곡

찾을 때 쓸 검색어: `ambient`, `dark`, `cinematic`, `suspense`, `drone`

## 넣는 법

1. 파일을 이 폴더에 넣습니다 (mp3)
2. `목록.json` 에 한 줄 추가합니다
3. 커밋합니다 — GitHub Actions는 실행할 때마다 서버가 새로 만들어지므로
   리포에 들어 있어야 쓸 수 있습니다

## ⚠️ 출처 표기

오디오 보관함 곡 중 일부는 **설명란에 출처를 적어야** 합니다.
받을 때 그 곡 옆에 표시가 나옵니다.

표기가 필요한 곡은 `목록.json` 의 `attribution` 에 **보관함이 알려준 문구를
그대로** 넣으세요. 그러면 영상을 만들 때 설명란에 넣을 문구로 뽑아줍니다.

적어야 하는데 안 적으면 저작권 신고가 들어올 수 있습니다.
