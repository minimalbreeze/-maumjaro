# 18화 — 야포츠 예측표 (2026-11-18 기준)

## ⚠️ 이 표를 쓰는 규칙

1. **5% 단위로만 적는다.** 소수점을 쓰면 계산한 척이 된다. 안 했다.
2. **근거 한 줄 없는 칸은 안 만든다.** 근거는 **등급·구단 사정·공개 발언**뿐이다.
   나이·연봉은 확인된 것만 쓴다.
3. 영상에서는 **전부 `[THEORY]`** 다. 설명문에도 "야포츠의 예측이고 공식 발표가
   아닙니다"를 적는다.
4. **나중에 채점한다.** 계약이 끝나면 맞은 것과 틀린 것을 세어서 공개한다.
   ⚠️ 이걸 안 하면 예측이 공짜 말이 된다. 틀린 것을 숨기면 다음 예측도 못 믿는다.
5. **금액은 예측하지 않는다.** 행선지만 한다 — 금액은 범위가 너무 넓어 찍기다.

## 바탕에 깔린 규정 (이게 예측의 뼈대다)

| 등급 | 데려가는 쪽이 내는 것 | 그래서 |
|---|---|---|
| **A** | 보호 20명 외 1명 + 연봉 200%, 또는 연봉 300% | 제일 비싸다 → **잔류 쪽으로 기운다** |
| **B** | 보호 25명 외 1명 + 연봉 100%, 또는 연봉 200% | 중간 |
| **C** | 보상선수 없이 연봉 150% | 제일 싸다 → **움직이기 쉽다** |

- **구단당 외부 영입 최대 3명**
- **롯데·키움은 승인 선수 0명** — 내보낼 사람이 없어 한도 3명을 온전히 쓴다
- **KT는 6명이 한꺼번에 나왔다** — 다 잡기 어렵다

# ⚠️ 쓰지 않을 것

1. **금액을 예측하지 않는다.** 행선지만 한다
2. **구단 이름을 찍지 않는다** — "두산이 박동원을 데려간다" 같은 말은 근거가 없다.
   "이적 가능성이 반반"까지만
3. **퍼센트를 계산한 것처럼 말하지 않는다.** "제 생각에는"을 붙인다
4. **채점을 약속하고 반드시 지킨다.** 안 지키면 다음 예측이 못 믿을 것이 된다
