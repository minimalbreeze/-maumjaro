# 야포츠 로고 — 제비 (2026-11-18 확정)

효성님이 꺼낸 것: "좋은 소식을 물어다 주는 제비로 로고를 바꿔 볼까."
고른 것: **단순 자세 · 흰색 · 판화톤 · 아래 YAPORTS**.

## 쓰는 파일

| 파일 | 어디에 |
|---|---|
| `yaports-profile-800.png` | **유튜브 채널 프로필.** 글자 포함, 800px |
| `yaports-mark-512.png` | 제비만. 글자가 뭉개지는 작은 자리 |
| `yaports-watermark-512.png` | **영상 안 워터마크.** 배경 없음(투명) |
| `yaports-*.svg` | 원본 벡터. 크기·색을 바꿀 땐 여기서 |

`build.py` 를 돌리면 SVG 네 벌이 다시 나온다. 모양은 `제비.path` 하나에서 온다.

## 어떻게 만들었나 — 손으로 안 그렸다

**SVG 로 손수 여섯 번 그려서 여섯 번 다 실패했다**(사람·별·비행기·가위).
좌표를 글로 쓰고 결과를 보는 되풀이로는 새 실루엣이 안 맞는다.

그래서 길을 둘로 나눴다.
1. **모양은 모델이 그린다** — `src/logo.mjs`, 실행 #100 의 '단순'
2. **벡터는 추적한다** — `trace.py` 가 그 PNG 를 SVG 패스로 딴다

2번이 핵심이다. 내가 못 그리는 것을 추적기가 정확히 한다.
potrace 를 못 깔아서 직접 썼다 — 임계값 → 마칭 스퀘어 → 더글러스-포이커 →
베지에. PIL 이 이 컨테이너에서 깨져 있어 ImageMagick 으로 읽는다.

## 세 번 돌려서 배운 것 ($0.58)

| 실행 | 나온 것 | 원인 |
|---|---|---|
| #98 | 자연사 삽화 | 깃털을 한 올씩 그려 48px 에서 검은 얼룩 |
| #99 | 아직 실사 | **'타투' 가 음영의 입구였다.** 타투를 부르면 깃털과 그라데이션이 따라온다 |
| #100 | ✅ 평면 2색 | '평면 2색 벡터 로고 마크' 로 바꾸고, **"값이 둘뿐"** 을 적었다 |

⚠️ **색을 막는 말보다 "값이 둘뿐"이 세다.** 제비의 빨간 목은 모델이 단단히
쥔 지식이라 #99 에서 색 금지를 두 번 적고도 샜다. 중간 톤이 없다고 하면
음영도 색도 같이 못 들어온다.
⚠️ **"아래 여백을 비워라"를 적으면 새가 작아진다.** #99 가 그래서 깨알이 됐다.
글자 자리는 SVG 로 얹을 때 만든다.
⚠️ **단순화하라고 하면 모델이 꼬리부터 줄인다.** 제비를 제비로 만드는 것이
그 긴 가위 꼬리인데, 짧아지면 그냥 비둘기다. #100 의 다섯 중 셋이 그랬다.

## 판화톤

feTurbulence 로 가장자리만 흔든다. **가는 부분이 흔들림에 약하다** —
1.5/1.3 으로는 꼬리 끝과 날개 끝이 갉아먹힌 것처럼 부서졌다. 네 단계를
나란히 놓고 **2.0 / 0.5** 를 골랐다.
⚠️ `scale` 을 0.5 보다 키우지 않는다. 굵은 몸통은 멀쩡해 보여도 꼬리가 먼저 깨진다.

## 베끼지 않은 것

효성님이 준 참고 사진은 **'SEASON COFFEE&BAKE' 라는 가게의 실제 간판**이다.
결(검정 바탕·흰 잉크·아래 글자)만 가져오고 제비 모양은 모델에게 새로 받았다.
남의 로고를 베끼지 않는다 — 로또·책 규칙과 같은 선이다.
