# 안드로이드 2차 비공개 테스트 — 테스터 안내문

2026-11-15 프로덕션 액세스 반려 후 다시 모집. 반려 사유는 두 가지였다.
1. 테스터가 앱에 참여하지 않았습니다 (14일간 활성 2명, 이벤트 5건)
2. 사용자 의견을 수집하고 업데이트로 조치하지 않았습니다

따라서 안내에 꼭 들어가야 할 것은 **둘뿐**이다.
- 하루 1~2분 써달라 (구글이 보는 건 연 사람 수)
- 불편한 점을 알려달라 (의견이 와야 릴리스 노트에 반영을 쓸 수 있다)

반려 얘기, 2주 얘기, 단계별 설명은 넣지 않는다. 길면 안 읽힌다.

## 업데이트 올릴 때마다 보내는 메시지

```
페이드캠 업데이트 올렸습니다.
한 번만 받아주시고, 하루에 1~2분만 써봐주시면 감사하겠습니다.

열어서 사진 한 장만 찍어주셔도 됩니다.
불편한 점 있으면 한 줄이라도 남겨주세요. 바로 고치겠습니다.
```

## 기간 중 반드시 할 것

- **업데이트 2번 이상.** iOS 2.6.3 기능을 안드로이드로 올리면 한 번 채워진다
- **릴리스 노트에 의견 반영을 명시.** "○○ 의견 → ○○ 수정" 형태
- 7일차에 vitals를 확인하고, 활성이 5명 아래면 개별 연락
